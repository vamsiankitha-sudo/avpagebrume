# AV Pagebrume

Static website for [AV Pagebrume](https://vamsiankitha-sudo.github.io/avpagebrume/), a small self-publishing brand. GitHub Pages serves these files from the `main` branch, root folder. There is no build step.

## Turn on GitHub Pages

After this site is on `main`:

1. Open the repository **Settings**.
2. Click **Pages** in the left sidebar.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Set **Branch** to `main` and the folder to **`/ (root)`**.
5. Save.

The site address is `https://vamsiankitha-sudo.github.io/avpagebrume/`.

## Search Console

In Google Search Console, add the URL-prefix property `https://vamsiankitha-sudo.github.io/avpagebrume/`. Paste the verification meta tag into `index.html`, then submit `sitemap.xml`.
